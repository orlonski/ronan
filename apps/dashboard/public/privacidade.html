Política de Privacidade

Aplicativo: Ronan Motorista · Última atualização: 02 de maio de 2026

Esta política descreve como o aplicativo Ronan Motorista coleta, usa e protege os dados dos motoristas que utilizam o sistema da transportadora Ronan.

1. Quem somos

O Ronan Motorista é um aplicativo de uso interno corporativo, distribuído aos motoristas autorizados da transportadora Ronan para registro de viagens (cargas, descargas, tickets) e pedágios.

2. Dados que coletamos

  • Dados de cadastro do motorista: nome, usuário, telefone, placa do veículo. Cadastrados pelo administrador da transportadora.
  • Dados de viagem: data, obra, material, toneladas, número de ticket, quilômetros, locais de carga e descarga, valor de pedágio, observações.
  • Foto do ticket: imagem capturada pela câmera do dispositivo, anexada à viagem para conferência.
  • Localização: latitude e longitude apenas dos locais cadastrados (carga, descarga, pedágios), não rastreamos a localização do motorista em tempo real.

3. Como usamos os dados

  • Para registrar e organizar as viagens da transportadora.
  • Para gerar planilhas de fechamento e conferir com as empresas-cliente.
  • Para padronizar endereços de locais (via Google Places API).
  • Não vendemos, compartilhamos ou comercializamos dados pessoais.

4. Onde os dados ficam

  • Servidor próprio da transportadora, em infraestrutura cloud na Alemanha (Contabo).
  • As fotos dos tickets ficam armazenadas em storage privado da transportadora.
  • Endereços buscados são processados pela API do Google Places para padronização.

5. Permissões usadas no dispositivo

  • Câmera: para tirar foto do ticket de carga e descarga.
  • Internet: para sincronizar viagens e pedágios com o servidor.
  • Armazenamento local: para guardar viagens em modo offline (quando o motorista está em local sem sinal) e sincronizar quando houver internet.
  • Keychain / EncryptedSharedPreferences: para armazenar tokens de autenticação de forma segura.

6. Modo offline

O aplicativo funciona sem internet: viagens e pedágios são salvos no armazenamento local do dispositivo e enviados automaticamente para o servidor quando a conexão volta. Os dados ficam armazenados criptografados no dispositivo.

7. Direitos do motorista

Conforme a LGPD (Lei nº 13.709/2018), o motorista tem direito a:

  • Saber quais dados são coletados.
  • Solicitar correção de dados incorretos.
  • Solicitar exclusão dos seus dados pessoais (sujeito a obrigações legais e contratuais com a transportadora).

Para exercer esses direitos, o motorista deve entrar em contato com o administrador da transportadora.

8. Segurança

  • Toda comunicação com o servidor é feita por HTTPS (TLS 1.2+).
  • Senhas são armazenadas no servidor com hash bcrypt.
  • Tokens de acesso são guardados no armazenamento seguro do sistema operacional (Keychain no iOS, EncryptedSharedPreferences no Android).

9. Crianças

O aplicativo não é direcionado a crianças e adolescentes. É de uso exclusivo de motoristas profissionais maiores de 18 anos contratados pela transportadora.

10. Mudanças nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização aparece no topo desta página.
